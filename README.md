# Pixaroid

Pixaroid is a browser-first collection of free image and PDF tools designed to process files locally in the browser whenever the tool supports it.

## Website

**Official website:** https://pixaroid.vercel.app/

Explore the main tool categories:

- https://pixaroid.vercel.app/tools/compression/
- https://pixaroid.vercel.app/tools/conversion/
- https://pixaroid.vercel.app/tools/pdf-tools/
- https://pixaroid.vercel.app/tools/ai-tools/
- https://pixaroid.vercel.app/tools/international/
- https://pixaroid.vercel.app/guides/

## Privacy

Pixaroid is designed around browser-side processing for supported tools, so files do not need to be uploaded to a server for those operations.

## Source

This repository contains the website and its client-side processing code. Contributions and issue reports are welcome.
