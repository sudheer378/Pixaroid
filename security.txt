# ============================================================
#  SECURITY NOTES
# ============================================================
# 
# Pixaroid is a client-side only application. All image and PDF
# processing happens in the user's browser using Web Workers
# and the Canvas API. No files are ever uploaded to our servers.
#
# This means:
# - No server-side file storage vulnerabilities
# - No file upload attack vectors
# - No database containing user files
# - No backend API for file processing
#
# Potential security concerns should focus on:
# - XSS vulnerabilities in client-side code
# - Dependency vulnerabilities (npm packages)
# - Service Worker security
# - PWA offline storage
# - Third-party CDN integrity
#
# We take security seriously and appreciate responsible disclosure.
