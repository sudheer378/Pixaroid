## Page optimization rules

1. Every Tier 1 page must be indexable and self-canonical.
2. A page that is noindex or canonicalizes elsewhere must not appear in the tool sitemap.
3. Each target page gets one primary search intent; avoid keyword stuffing.
4. Title should clearly state the task, outcome, and Pixaroid brand where space allows.
5. Meta description should explain the unique benefit: browser-based, no upload, free, privacy-first.
6. H1 should closely match the page's primary task.
7. Add useful explanatory copy below the tool: what it does, how it works, supported formats/limits, privacy, and FAQs.
8. Link from category pages and related tools to each Tier 1 page using descriptive anchors.
9. Do not invent ratings, review counts, performance claims, or unsupported capabilities.
10. Keep duplicate variants consolidated through canonical URLs rather than indexing every keyword permutation.

## Priority order

P1: compression, JPG/PNG/WebP conversion, resizing, background removal, PDF conversion/compression.
P2: OCR, upscaling/enhancement, social-media sizes, passport photo, common editors.
P3: long-tail variants after P1/P2 pages have strong content and internal links.
