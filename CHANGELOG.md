# Changelog

All notable changes to Pixaroid will be documented in this file.

The format is based on [Keep a Changelog](https://keepachangelog.com/en/1.0.0/),
and this project adheres to [Semantic Versioning](https://semver.org/spec/v2.0.0.html).

## [2.1.0] - 2026-09-01

### 🚀 Added
- **12 New International Tools** for global users:
  - Currency Converter (150+ currencies with real-time rates)
  - Timezone Planner (compare multiple timezones)
  - Text Translator (100+ languages with auto-detect)
  - Phone Code Finder (50+ countries with flags)
  - Unit Converter (length, weight, temperature, volume, area)
  - Holiday Calendar (15+ countries worldwide)
  - Passport Photo Resizer (multiple country formats)
  - VAT Calculator (all EU countries + UK)
  - Paper Size Converter (A/B/C series + North American)
  - Script Detector (50+ writing systems)
  - Address Formatter (50+ countries)
  - Packing List Generator (customized travel lists)

### 🎨 Changed
- **Dashboard Redesigned**: Added International category as first tab in tool navigation
- **Tool Count Updated**: Total tools increased from 108 to 120
- **Category Order**: International tools now appear first for better visibility

### 🔧 Fixed
- Fixed missing tool entries in main dashboard TOOLS array
- Corrected category mapping for international tools
- Updated tool counts in tab navigation

### 📈 SEO/AEO Improvements
- All international tools include comprehensive meta tags
- Schema.org JSON-LD structured data for each tool
- Open Graph and Twitter Card metadata optimized
- Canonical URLs pointing to pixaroid.vercel.app domain

## [2.0.0] - 2026-09-01

### 🚀 Added
- Legal pages: Privacy Policy, Terms of Service, Disclaimer, Cookie Policy
- Complete sitemap system (sitemap.xml, sitemap-tools.xml)
- Google Search Console & Bing Webmaster verification files
- AI chatbot crawling configuration
- robots.txt with modern bot rules

### 🎨 Changed
- Domain updated from imagetotext.info to pixaroid.vercel.app everywhere
- Dashboard redesigned with improved performance
- Removed duplicate tool headings
- Enhanced mobile responsiveness

### 🧹 Removed
- Cleaned up 12 unnecessary summary/documentation files
- Removed old SEO/AEO legacy files
- Deleted outdated legal pages
- Removed duplicate sitemap files

### 🔒 Security
- Updated privacy policy for GDPR & CCPA compliance
- Enhanced cookie policy disclosure
- Improved terms of service
